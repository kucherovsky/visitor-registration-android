# Регистрация посетителей

Автономное Android-приложение для регистрации посетителей и печати этикеток на сетевых TSPL-принтерах. Сервер и подключение к интернету для работы не требуются.

## Сценарий MVP

1. Оператор выбирает тип списка: партнёры или сотрудники.
2. Загружает локальный Excel-файл.
3. Ищет посетителя по фамилии или имени.
4. Подтверждает регистрацию и печатает этикетку.
5. Если посетителя нет в списке, добавляет его вручную.
6. После мероприятия выгружает Excel со всеми пришедшими.

## Уже заложено в проект

- интерфейс регистрации и поиска;
- форма добавления незаявленного посетителя;
- выбор типа импортируемого списка;
- выбор локального `.xlsx` файла;
- настройки IP-адреса и порта принтера;
- проверка TCP-соединения;
- тестовая печать на TSPL-принтере;
- единая модель посетителя и интерфейсы для локальной базы, импорта и печати.

## Следующие этапы

- локальная база Room;
- разбор двух согласованных форматов Excel;
- импорт с проверкой ошибок и дублей;
- регистрация и печать реального бейджа;
- экспорт списка пришедших в Excel;
- сохранение настроек принтера;
- тесты на реальном принтере и планшете.

## Технологии

- Kotlin;
- Jetpack Compose;
- локальная база Room;
- прямое TCP-соединение с TSPL-принтером;
- минимальная версия Android: 8.0.
